# CLEMENT by Napoleon

Portafolio de Carlos Napoleón García Gutiérrez: ingeniería aeronáutica, desarrollo full-stack y análisis de datos.

Sitio estático en un solo archivo (`index.html`). GSAP + ScrollTrigger para parallax y zoom, Lenis para el scroll suave, Hanken Grotesk y Geist Mono desde Google Fonts. Respeta `prefers-reduced-motion`.

Para verlo en local abre `index.html` en el navegador.
